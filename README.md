# Inquin.pl

**Status:** Projekt zakończony
Inquin.pl to mini-serwis komputerowy, którego celem było umożliwienie klientom zapoznania się z ofertą usług serwisowych, zgłaszania urządzeń do naprawy oraz uzyskiwania propozycji zestawów komputerowych.
Projekt obejmował tworzenie strony internetowej z wykorzystaniem PHP, MySQL, HTML, CSS i Bootstrap, a także wybrane funkcjonalności panelu administracyjnego.
**Informacja:** Przy realizacji projektu korzystano z pomocy sztucznej inteligencji.
